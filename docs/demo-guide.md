# Demo guide

1. Launch the app and open the frontend.
2. Log in with the demo account.
3. View the dashboard cards and sample pantry items.
4. Use the Food Scanner page to confirm a supported ingredient or fallback.
5. Add the ingredient to the pantry and open recipe recommendations.
6. Open a recipe, review missing ingredients, and push them to the shopping list.
7. Add a planned meal to the weekly planner.
8. Use the OCR page to test expiry date extraction.
9. Review notifications, storage recommendations, and analytics.

This guide is intended for a quick college demonstration without requiring internet access.
